# Demo video plan — 2 minutes 35 seconds

This is a script/shot list, not a hosted video. `evidence/demo.mp4`, if present, is an actual silent browser walkthrough, not a narrated final submission. No YouTube/Vimeo upload or embed has been performed.

| Time | Shot | Suggested narration |
|---|---|---|
| 0:00–0:15 | Hero and synthetic/student-status notices | “AgriEvidence is a local-first workspace for small agriculture and environment research collections. Every excerpt keeps a source behind it. This demo uses synthetic notes, not real research or official advice.” |
| 0:15–0:40 | Source library; soil monitoring results | “Paste or upload authorized plain text. The free baseline is deterministic search, not AI. A search finds exact source statements, with stable source and line locators for this session.” |
| 0:40–1:00 | Expand original source context | “Open a citation to inspect the original numbered lines. We do not turn a small fictional observation into a causal claim or pretend a quote is scientifically verified.” |
| 1:00–1:15 | Search carbon credits | “When the corpus has no evidence, the app says so. It does not invent an answer to fill the space.” |
| 1:15–1:40 | Search again; download brief; inspect dates/select deadline/export ICS | “Export a brief with excerpts and a reference index. The date ledger separates mentions from possible deadlines. Nothing is selected for you. Review context, then export all-day reminders rather than a made-up cutoff time.” |
| 1:40–2:05 | Add an authorized pasted note and search it | “Sources stay in this browser tab. There is no analytics, account or cloud storage. Refresh removes imports. Download only what you want to keep.” |
| 2:05–2:25 | Expand optional model UI; show tests/report, not fabricated live inference | “An optional local Ollama model can select relevant lines. It cannot write new factual prose: schema and exact-citation validation reject invented quotes. Model transport tests here are mocked; this demo does not claim actual model inference.” |
| 2:25–2:35 | Final hero / repository | “AgriEvidence makes evidence easier to inspect and uncertainty harder to miss. Code is MIT licensed and AI assistance is disclosed. Student enrollment is confirmed; final rules acceptance and submission stay with the entrant.” |

Record at <=3 minutes including titles. For GenHacks, upload the final video to YouTube/Vimeo, check public/unlisted playback, and embed it in the project page after personal rules review. Avoid private source text in the recording.
